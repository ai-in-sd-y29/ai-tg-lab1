# Демонстрация лабораторной 2

1. Установить зависимости, запустить PostgreSQL и бот по README.
   Не запускать локальный polling одновременно с облачным для одного BOT_TOKEN.
2. `/start`: команды lab1 и `/tools`, `/timezone`, `/why`. `/tools`: три обнаруженных инструмента.
3. `/timezone Europe/Unknown`: отказ; `/timezone Europe/Moscow`: зона и локальное время.
4. «Какая погода в Тбилиси, Грузия?» — уточнение области для одноимённых городов.
   «Тбилиси, Грузия, Тбилиси» — значения Open-Meteo с источником; `/why` — аргументы и статус.
5. «Расписание на 12 ноября 2026» — строки учебного JSON; на 15 ноября — занятий нет.
6. «Кратко объясни список Python» — ответ без MCP. `/translate`, `/quiz`, `/settings`, `/reset`
   продолжают работать; `/why` не раскрывает системный промпт и чужую историю.
7. «Напомни вечером про лабораторную» — уточнение даты/времени.
8. «Через два часа напомни сделать перерыв» — подготовка и две кнопки; до согласия напоминания нет.
   Отменить — записи не создаётся. Повторить и подтвердить — ID и время с зоной.
9. Повторное нажатие не создаёт дубликат. Новая подготовка с ожиданием более пяти минут — отказ.
10. Второй аккаунт не видит данные первого; без `/timezone` локальное время не угадывается.
    Чужое подтверждение отклоняется. После перезапуска `/timezone` и `/why` сохранены.
11. `python -m scripts.lab2_inspect --live-weather`: независимый клиент показывает discovery,
    недельный ресурс, день и отказ изменения без capability.
12. Показать RUN_INTEGRATION=1 python -m pytest -q, Ruff, pip check; обратить внимание
    на конкуренцию в настоящей PostgreSQL и настоящий stdio-процесс.
13. Показать baseline/final таблицы: 11/12 → 12/12 действий, 8/9 аргументов.
    Единственное строгое несовпадение в финале — регистр первой буквы текста напоминания.
14. Показать AGENTS.md, spec.md, plan.md, Word-отчёт и тег lab2.

## Проверенные негативные сценарии

| Категория | Тест | Безопасный результат |
|---|---|---|
| Неизвестный инструмент, подмена владельца | test_unknown_tool_and_extra_fields_never_execute | MCP и подготовка не выполняются |
| Инъекция из результата | test_tool_injection_remains_untrusted_and_cannot_select_owner | Данные остаются tool-сообщением, owner отклоняется |
| Неоднозначное/прошедшее время | test_dst_nonexistent_and_ambiguous, test_reminder_requires_text_and_timezone | Отказ до подготовки |
| Отказ MCP/погоды | test_corrupt_tool_result_and_disconnect_are_safe, test_weather_timeout_and_bad_json | Безопасная ошибка без ложного успеха |

Реальные сообщения, Telegram ID и секреты в материалы защиты не включать.
Автоматизированная демонстрация с синтетическими updates не заменяет показ преподавателю.
