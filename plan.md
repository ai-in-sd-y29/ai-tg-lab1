## Проверенные решения и отклонения

- MCP SDK 2.3.0 вместо старых примеров FastMCP 1: использованы актуальные lowlevel handlers.
- Yandex запрещает tools и response_format в одном запросе. Нативное решение отделено от
  строгого JSON-ответа. Проверено реальным API, тест закрепляет два разных payload.
- Набор получен из официального шаблона, локально отсутствовал; сохранён без изменений с SHA-256.
- Первый прогон 11/12 и 8/9. Добавлено только правило для относительных интервалов;
  повтор исходного сбоя и полный итог 12/12 и 8/9 сохранены, несовпадение регистра не скрыто.
- Сквозной тест обнаружил UTC из PostgreSQL вместо локального времени при подтверждении.
  Исправлено явное преобразование и добавлен регрессионный тест.
- Независимый stdio-клиент, реальная погода, восемь конкурентных повторов подготовки и
  подтверждения, сохранность после перезапуска PostgreSQL проверены.
- Облачная ВМ была STOPPED и не запускалась: ручная демонстрация в Telegram остаётся
  действием на защите. Сквозной прогон использует настоящий backend с синтетическим транспортом.
